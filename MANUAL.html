Ubuntu no MacBook Air

Troque o macOS pelo Xubuntu 26.04 já configurado, com teclado de Mac, Claude Desktop e Claude Code. Marque cada etapa ao terminar: o progresso fica salvo neste aparelho.

Você vai precisar de

  • Pendrive de 8 GB ou mais (ele será apagado)
  • Carregador do Mac ligado na tomada o tempo todo
  • Cabo USB do celular, para a internet durante a instalação

Parte A

No macOS, antes de apagar

Tudo aqui acontece no Mac como ele está hoje.

A1

Fazer backup

A instalação apaga o disco inteiro. Copie para a nuvem ou um HD externo: documentos, fotos, downloads, área de trabalho, favoritos e senhas do navegador.

Confira se o backup abre em outro aparelho antes de seguir. Para voltar ao macOS depois, veja F7.

A2

Repositório público ou privado

O comando da Parte C baixa os scripts do GitHub (LifeB69/Ubuntu-Mac). Escolha um caminho:

Público (mais fácil)

No GitHub: repositório → Settings → General → Danger Zone → Change visibility → Public. Não há senhas nem dados pessoais nele.

Privado

Sem problema. Na etapa C3 você baixa o ZIP pelo Firefox, já logado no GitHub.

A3

Baixar o Xubuntu

Arquivo de cerca de 5 GB:

xubuntu-26.04.1-desktop-amd64.iso

A4

Conferir se o arquivo veio inteiro

Abra o Terminal (⌘ Espaço → "Terminal") e rode:

Terminal do macOS
shasum -a 256 ~/Downloads/xubuntu-26.04.1-desktop-amd64.iso

O resultado tem que ser exatamente:

0cd5160f72ae6b7a26be7a29248b60cbd579b9e6aa8fbd274e95264da0ade43d

Se for diferente, apague o arquivo e baixe de novo.

A5

Gravar o pendrive

  1. Instale o balenaEtcher, versão para macOS. Ele exige macOS 11 ou mais novo; o Monterey (12) atende. Se o macOS bloquear: Preferências do Sistema → Segurança e Privacidade → Abrir Mesmo Assim.
  2. No Etcher: Flash from file → escolha o .iso → Select target → escolha o pendrive (confira o tamanho) → Flash!
  3. Digite a senha do Mac e espere o "Validating" terminar. Se o macOS disser que "o disco não pode ser lido", clique em Ejetar: é normal.
Sem o Etcher, pelo Terminal
1 · achar o pendrive pelo tamanho
diskutil list

Nos comandos abaixo, troque disk2 pelo número do seu pendrive. Errar o número apaga o disco errado.

2 · desmontar
diskutil unmountDisk /dev/disk2
3 · gravar (5 a 15 min · Ctrl+T mostra o progresso)
sudo dd if=$HOME/Downloads/xubuntu-26.04.1-desktop-amd64.iso of=/dev/rdisk2 bs=4m
4 · ejetar
diskutil eject /dev/disk2
Parte B

Instalar o Xubuntu

Daqui em diante o macOS deixa de existir.

B1

Ligar pelo pendrive

  1. Desligue o Mac. Coloque o pendrive e o carregador.
  2. Ligue segurando ⌥ até aparecerem os ícones de disco.
  3. Escolha o ícone amarelo EFI Boot e aperte ↩.
  4. No menu preto, escolha Try or Install Xubuntu.
B2

Internet pelo celular

O Wi-Fi do Mac ainda não funciona nesta etapa, porque falta o driver. Use o cabo:

Android

Conecte o cabo → Configurações → Rede e Internet → Ponto de acesso → Ancoragem USB.

iPhone

Conecte o cabo → toque em Confiar → Ajustes → Acesso Pessoal → Permitir que outros acessem.

No canto superior direito deve aparecer o ícone de rede com fio.

Dá para testar antes de apagar: escolha "Experimentar o Xubuntu" e confira teclado, touchpad, som e tela. Para instalar depois, use o ícone "Instalar Xubuntu" na área de trabalho.

B4

Reiniciar

Clique em Reiniciar agora. Quando pedir, tire o pendrive e aperte ↩. Guarde o pendrive: ele tem o driver do Wi-Fi de reserva (F3).

Se o Mac não iniciar no Ubuntu sozinho, ligue segurando ⌥ e escolha EFI Boot (agora o do disco interno). Depois disso costuma ir direto.

Parte C

O comando que configura tudo

Um comando faz drivers, teclado, touchpad, bateria, programas e aparência.

C1

Entrar e conectar

  1. Entre com a sua senha.
  2. No ícone de rede (canto superior direito): se aparecerem redes Wi-Fi, conecte na de casa. Se não aparecer nenhuma, continue com o celular no cabo; o script instala o Wi-Fi.

Espere uns 5 minutos depois do primeiro login. O Ubuntu termina a preparação inicial em segundo plano. Se rodar antes, o script espera; só demora mais.

C2

Abrir o Terminal

Aperte Ctrl Alt T. No Mac são as teclas ⌃ ⌥ T.

Até o script rodar, as teclas são as do Linux: o ⌘ ainda não funciona como no Mac. Para copiar o comando abaixo, abra este manual no Firefox do próprio Mac, copie com Ctrl C e cole no Terminal com Ctrl ⇧ V.

C3

Rodar o comando

Repositório público:

Terminal do Xubuntu
wget -qO- https://raw.githubusercontent.com/LifeB69/Ubuntu-Mac/main/comecar.sh | bash

Repositório privado: no Firefox, entre no GitHub → LifeB69/Ubuntu-Mac → Code → Download ZIP. Depois:

Terminal do Xubuntu
cd ~/Downloads && unzip -oq Ubuntu-Mac-*.zip && bash Ubuntu-Mac-*/comecar.sh
C4

Esperar de 20 a 40 minutos

  • Ele pede a sua senha uma vez. Ao digitar, nada aparece na tela; é normal.
  • Cada passo mostra OK, FALHOU ou pulado, e os longos mostram o tempo decorrido. "Atualizar todos os pacotes" pode levar de 10 a 20 minutos.
  • Se algo falhar, ele não para: anota e segue.
  • Deixe a tampa aberta e o carregador ligado. A tela não bloqueia e o Mac não suspende enquanto ele roda; se a tela apagar, mexa no touchpad.
C5

Reiniciar

No fim aparece um resumo e a pergunta "Reiniciar agora? [s/N]". Digite s e ↩.

Teve falhas? Rode de novo depois de reiniciar (D1). É seguro repetir, e muitas somem na segunda vez.

Parte D

Depois de reiniciar

Conferir, entrar no Claude e deixar o ajuste fino com ele.

D1

Conferir se está tudo certo

No Terminal (⌃ ⌥ T):

Terminal do Xubuntu
ubuntu-mac --verificar

Mostra ✔ ou ✘ para Wi-Fi, memória, bateria, teclado, touchpad, gestos, programas e dock, com a dica de como resolver cada ✘. Para rodar a instalação de novo, digite só ubuntu-mac.

D2

Entrar no Claude Desktop

Clique no ícone do Claude na dock e faça login. Feche e abra de novo para confirmar que o login ficou salvo.

D3

Claude Code: o ajuste fino

Terminal do Xubuntu
cd ~/Ubuntu-Mac && claude

Faça login e peça: "leia o CLAUDE.md e faça a checagem pós-instalação". Ele lê os logs, corrige o que falhou e testa com você o que só dá para testar no Mac: suspensão, webcam, ventoinha e gestos.

D4

Opcional: o Claude usando o navegador

  1. Abra o Google Chrome (Menu → Internet).
  2. Instale a extensão Claude pela Chrome Web Store e entre com a mesma conta.
  3. No Claude Code, digite /chrome.

No Firefox essa extensão não existe; ele continua sendo o navegador do dia a dia.

Parte F

Se algo der errado

F1Segurando ⌥, o "EFI Boot" não aparece

Grave o pendrive de novo (A5), use a outra porta USB e segure ⌥ antes do som de inicialização.

F2Sem internet no instalador

Android: desligue e ligue a Ancoragem USB. iPhone: desconecte, reconecte, toque em Confiar e deixe a tela do Acesso Pessoal aberta. Se não der, instale sem internet: o driver do Wi-Fi vem no pendrive.

F3Depois de instalar, o Wi-Fi não aparece

Conecte o celular no cabo e rode o comando da C3: o script instala o driver.

Sem internet nenhuma: conecte o pendrive do Xubuntu, abra-o no gerenciador de arquivos (para ele ser montado) e rode:

Terminal do Xubuntu
sudo apt install /media/$USER/*/pool/main/d/dkms/dkms_*.deb /media/$USER/*/pool/restricted/b/broadcom-sta/broadcom-sta-dkms_*.deb

Reinicie, conecte no Wi-Fi e siga da C3.

F4"Não consegui baixar o projeto do GitHub"

O repositório está privado. Use o caminho do ZIP (C3, segunda opção).

F5"O Ubuntu-Mac já está rodando em outro terminal"

Outra janela ainda está instalando. Espere ela terminar.

F6Algum passo deu FALHOU

Rode ubuntu-mac de novo. Se continuar, abra o Claude Code em ~/Ubuntu-Mac e peça "leia logs/ultimo e resolva as falhas". Os detalhes ficam em ~/Ubuntu-Mac/logs/ultimo/.

F7Quero o macOS de volta

Desligue e ligue segurando ⌥ ⌘ R (Recuperação pela Internet, precisa de Wi-Fi) → Utilitário de Disco: apague o disco interno (APFS) → Reinstalar o macOS.
